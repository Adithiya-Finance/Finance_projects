# AP Invoice Analysis & Dashboard

## Project Overview

Built an Accounts Payable (AP) Invoice Analysis and Dashboard using Microsoft Excel to analyze invoice transactions, payment status, vendor spending, department spending, and invoice aging.

## Objectives

- Track invoice payment status
- Analyze total invoice value
- Identify pending and overdue invoices
- Analyze vendor-wise invoice spending
- Analyze department-wise invoice spending
- Monitor invoice aging
- Create an interactive management dashboard

## Dataset

- Total invoices: 10
- Total invoice value: ₹197,500
- Paid invoices: 5
- Pending invoices: 3
- Overdue invoices: 2

## Key Results

| Metric | Result |
|---|---:|
| Total Invoice Value | ₹197,500 |
| Paid Amount | ₹94,000 |
| Pending Amount | ₹46,500 |
| Overdue Amount | ₹57,000 |
| Unpaid Amount | ₹103,500 |
| Pending Invoice % | 30% |
| Overdue Invoice % | 20% |
