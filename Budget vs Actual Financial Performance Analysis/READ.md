# Budget vs Actual Financial Performance Analysis

## Business Problem

Organizations need to monitor actual expenditure against approved budgets to identify unfavorable variances, understand cost drivers, and support financial decision-making.

This project analyzes budget versus actual expenditure across departments, expense categories, vendors, and months.

## Objective

- Compare budgeted and actual expenditure
- Calculate absolute and percentage variances
- Identify unfavorable spending
- Analyze department-level performance
- Analyze expense-category drivers
- Identify monthly spending trends
- Create a management-oriented financial dashboard

## Tools

- Microsoft Excel
- Excel formulas
- Conditional Formatting
- Financial KPI Analysis
- Dashboarding

## Dataset

The project uses a synthetic FY2026 dataset containing:

- 1,000 transactions
- 6 departments
- 8 expense categories
- 10 vendors
- 12 months

## Key Calculations

### Variance

`Variance = Actual - Budget`

### Variance %

`Variance % = Variance / Budget`

For expense analysis:

- Positive variance = unfavorable
- Negative variance = favorable

## Analysis

The analysis is performed across:

### Department

- Finance
- HR

- Sales

### Expense Category

- Salaries
- Software
- Travel

### Time

Monthly budget versus actual analysis from January to December 2026.

## Dashboard

The dashboard includes:

- Total Budget
- Total Actual
- Total Variance
- Overall Variance %
- Budget vs Actual by Department
- Monthly Budget vs Actual
- Variance by Expense Category

The analytical process follows:

Raw Data  
→ Budget vs Actual

→ Department Analysis  
→ Expense Driver Analysis
