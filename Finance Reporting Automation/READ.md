# Finance Reporting Automation

## Project Overview

This project demonstrates the automation of a recurring finance reporting process using **Python, SQL and Excel**.

The objective is to transform transaction-level finance data into a standardized management report with:

- Data-quality checks

- Monthly expense analysis

- Budget vs actual analysis

- Department analysis

- Category analysis

- Financial KPIs

- Management dashboard

The dataset is a **synthetic portfolio simulation** created for learning and demonstration.


## Business Objective

Finance reporting often involves repetitive activities:



Receive transaction data

        ↓

Clean the data

        ↓

Validate the data

        ↓

Calculate KPIs

        ↓

Analyze variances

        ↓

Prepare Excel report

        ↓

Create management summary
