# Project 5 — Finance Reporting Automation

## Objective
Automate a recurring finance reporting process from transaction-level data through data-quality validation, KPI calculations, SQL analysis and an Excel management report.

## Portfolio positioning
This project demonstrates:
- Python / Pandas
- SQL
- Excel reporting
- Data validation
- Budget vs actual analysis
- KPI reporting
- Reusable finance-reporting workflow

## Files
- `Project_5_Finance_Reporting_Automation.xlsx`
- `Project_5_Finance_Reporting_Automation.py`
- `Project_5_Finance_Reporting_Automation.sql`

## Workbook flow
Raw_Data → Data_Quality → Monthly_Analysis → Department_Analysis → Category_Analysis → Dashboard → Insights.

## Reverse engineering
Start with the `Reverse_Engineering` worksheet. Trace each KPI backwards to the transaction-level data and understand:
1. What the formula does
2. What business question it answers
3. Why the KPI matters
4. How the same calculation could be automated in Python/SQL

## Important
The dataset is synthetic and created for portfolio practice. Do not represent the transactions or results as actual employer/client data.

## Suggested interview description
> Built an automated finance reporting workflow using Python, SQL and Excel to validate transaction-level data, calculate monthly expense and budget variance KPIs, analyze departmental/category spending and generate a management-ready reporting layer.

Do not claim a specific percentage reduction in reporting time unless you have actually measured it.
